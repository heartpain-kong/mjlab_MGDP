# 跨越技能实验：横移、落脚、越墙

> 后续局部减速更新：新训练高墙附近和绕桩上限均为0.25m/s；下文0.35为初版实验配置。详细范围、门控补偿及旧模型兼容见[局部减速说明](MGDP_OBSTACLE_SPEED.md)。

这是“比赛尺寸强化课程”及D435i下俯20度版本的显式可选实验，默认不勾选。工作台新增“技能引导实验”和0.2～0.5动作映射输入。新建训练或仅迁移旧策略；不要完整续训不同规则的检查点。没有勾选时保留已有奖励设置。

## 旧参数的实际含义

防刷分与教会动作是不同目标。当前高墙正奖励门控只作用在高墙列：参考0.6m/s时，以0.2m/s创造新最远距离只能取得约1/3的基础正奖励，原地准备不能取得这些正奖励。等待扣分最大3分/秒，若从进入等待状态开始完全没有有效进展，连续4秒的连续时间积分约为7.5分（0.75秒宽限、1.5秒线性上升、其余时间最大扣分），大于完整越墙一次+5。实际离散采样、刷新进展与终止时刻会改变这个数。

`is_terminated=-200`仍经过控制步长缩放；控制间隔0.02秒时一次失败约扣4分，不是一次扣200分。每墙奖励和出口奖励的函数除以步长，因而分别是固定+5和+10。新增距离奖励在未触及速度裁剪时约为每米1.5分。不能直接比较配置表里的权重大小来判断实际贡献。

## 实验变更

| 项目 | 已有基线 | 勾选技能实验 |
|---|---|---|
| 高墙正奖励完整参考速度 | 0.6m/s | 0.15m/s |
| 等待宽限/上升时间 | 0.75/1.5秒 | 1.5/2秒 |
| 最大实际等待扣分 | 3分/秒 | 0.5分/秒（若原项已禁用仍禁用） |
| 平移无进展终止 | 4秒 | 6秒 |
| 每墙/出口完整奖励 | +5/+10 | 保留已有配置 |
| 过程反馈 | 墙顶摆腿不足代价 | 增加有限的抬脚高度进展和每脚一次越墙反馈 |
| 梅花桩每排数量 | 全部6个 | 2、3、4、5、6、6、6、6个 |
| 梅花桩反馈 | 终止、路线进度、完整出口 | 增加正确排、有效桩面承重落脚每脚每桩一次+0.25 |
| 绕桩 | 每段对齐后前进 | 保持入口朝向，允许前后和横移，局部巡航上限0.35m/s |

高墙新过程反馈每脚每墙最多抬脚进展0.25分、越墙0.25分，四脚合计上限2分/墙；高度取新的最高值，反复抬放不重复领取。它引导跨越，不强迫腾空或翻滚。完整越墙仍需满足根部与四脚条件，躯干/腿部碰撞判定保留。

梅花桩高度、宽度、30cm错位和60cm间距保留。早期只缩短阵列并移动出口平台，地面禁踩区域同步缩短。第五档起恢复完整六个桩，第六档比赛尺寸以及更高档几何与原配置一致。落脚奖励使用每物理子步接触力、接触位置与法线，扣除足球半径和边缘余量；站住、反复落回同一桩、踩地、侧面接触或已失败的回合不重复给分。完整验收应使用第六档完整阵列。

横移路线把换道安排在身体后部越过桩之后，保留身体投影碰桩终止和原有路线偏离判定。理想指令积分的身体包络检查不等于真实策略能稳定横移，也不覆盖摆腿或剧烈俯仰。固定朝向会使部分障碍处于相机侧方，需要实际验证视觉记忆与横移能力。

## 动作映射0.5

动作执行先裁剪到±1，再乘映射、加默认关节角；0.5允许最大目标偏移±0.5弧度，0.3则为±0.3弧度。相同原始动作与标准差下，目标变化放大约1.67倍。它既扩大动作范围，也可能增大冲击、力矩饱和和姿态不稳定；不等于步长0.5米，也不保证能跳。建议同配置分别运行0.3和0.5对照。

## 启动与检查点

CLI在原训练命令后添加`--mgdp-skill-training=True --mgdp-action-scale=0.5`。实验的部分参数会覆盖面板保存的基线，以上表和训练归档`params/env.yaml`为准；面板保存不会热更新正在运行的训练。保持高墙正奖励门控启用，实验会将其参考速度改为0.15。

检查点记录技能实验版本和实际动作映射，Play自动恢复实验路线、短阵列及动作映射。感知权重继续要求与检查点匹配。本次没有重新训练感知模型。

先比较第一档跨墙次数、每脚桩面落脚、绕桩路点完成数，再看完整通过率和升档。分多种种子、完整回合样本统计，固定比赛尺寸无探索噪声评估。工程测试和小规模CPU回合只能检查实现，不能证明GPU训练收敛。

# 强化课程的地形学习调整（2026-11-16）

适用于比赛尺寸强化课程和D435i下俯20度版本。巡航从0.6m/s起步，扩速上限2.0m/s，动作映射0.3，已有奖励参数及工作台覆盖继续生效。

## 检查发现

旧逻辑把成功通过和整回合平均XY速度误差不超过0.25m/s同时作为地形升级条件。跳墙、落地或绕桩的减速可能使成功回合无法升级。旧逻辑还在一次成功后立即升档，一次失败后立即降档，域随机化带来的偶发失败可能让环境反复跳档。这些是代码层面的限制；仅凭V6的低通过率不能证明它们就是高墙和梅花桩学不会的唯一原因。

## 新规则

| 项目 | 旧强化课程 | 新强化课程 |
|---|---|---|
| 地形升档 | 一次成功且平均XY误差≤0.25 | 同一环境连续成功2回合 |
| 地形降档 | 一次失败 | 同一环境连续失败2回合 |
| 扩速 | 每列至少32回合，通过率≥70%、平均XY误差≤0.25，连续3窗口 | 保留 |
| 上下限 | 最低第一档，最高第八档 | 保留 |
| 完整续训 | 恢复旧统计 | 新增每环境升降档计数的保存恢复，并拒绝不同升降档规则 |

成功仍要求到达完整路线出口且没有同时触发失败。失败包括碰撞、越界、无进展等，不将只跨过第一道墙视为完整通过。未完成的初始随机长度回合不计入课程。普通Race-MGDP任务保留原规则。

计数属于每个环境，跨回合保留；升降档后清零。升档所需成功不能跨失败累计。达到最高档后保留最高档，不随机回落。速度扩展仍需要所有地形达标，因此高墙和梅花桩未掌握时速度可以长期保持0.6。

## 新增TensorBoard指标

在`Curriculum/passage/`下新增`tracking_error/<地形>`、`level_mean/<地形>`、`lowest_fraction/<地形>`，配合原有`samples/<地形>`和`success_rate/<地形>`观察。通过率和误差仍来自当前课程窗口；窗口清空后需重新积累样本。难度均值为内部0～7档，最低档占比为0～1。

## 使用与验证边界

已运行的训练不会自动改变。旧检查点可用工作台“仅迁移旧策略，新建课程和优化器”启动；规则不同的检查点不能完整续训。应保持相同环境数、种子和独立评估条件，比较各地形通过率、难度分布、动作裁剪和真实回合数。连续两次通过只是较弱的掌握判据，仍需无探索噪声的独立比赛尺寸评估；本次代码验证不证明收敛速度或最终通过率提高。

八档障碍几何、比赛尺寸第六档、高墙10cm起步、梅花桩错位和地面接触判定均未在本次更改。几何合同由`tests/test_mgdp_course_v4.py`等编译检查验证。

# 高墙和绕桩局部减速（2026-11-16）

比赛尺寸强化课程及D435i下俯20度版本的新训练：全局巡航从0.6m/s起步，课程扩速上限仍为2.0m/s。高墙中心前后各0.6米的区间，将平移目标上限设为0.25m/s；仅对当前难度实际存在的墙生效，离开最后一道墙的减速区间后恢复当前巡航目标。绕桩接坑整条路线的平移目标上限为0.25m/s，横移技能实验也使用该上限。靠近路点仍可继续减速，停车对齐时仍可能为零；限速不会强行抬高较低的巡航指令。

减速区由根部位置判断，并非实时检测四脚是否全部越墙。它给跨越和落脚更多时间，但不保证通过；跳跃可能需要助跑动量，须对照实际跨越表现，不能无限降低速度。

启用局部限速时，高墙基础正奖励的进展参考值取面板参考速度与当前平移指令速度的较小值。因此，面板参考0.6而局部指令0.25时，实际新增进展达到0.25m/s也可取得完整门控系数；停止前进仍不能刷基础正奖励。技能实验参考0.15时仍使用不超过0.15的参考值。其余奖励权重和等待惩罚不因此改变。

TensorBoard新增`Curriculum/passage/wall_speed_limit`与`slalom_speed_limit`，工作台在巡航范围旁显示日志中的局部上限。已有训练不热更新，只有新启动训练读取新配置。

检查点保存`infos.mgdp_obstacle_speed`。旧模型Play恢复原指令行为：未记录局部限速的旧检查点不施加新限速，旧版横移实验保留原0.35上限。新旧限速规则不同不能完整续训，可通过“仅迁移旧策略，新建课程和优化器”启动新实验。

# 比赛尺寸强化课程：技能实验 V2

适用任务为 `LgDog1-Race-MGDP-WallTraining` 与
`LgDog1-Race-MGDP-WallTraining-D435i20`。工作台勾选“技能引导V2”后，新启动的
训练才使用本实验。未勾选时保留原配置；保存的基础奖励权重不被本实验写回。

## 为什么改

MGDPV8_0V8 的 V11 检查点回放显示：梅花桩初级右侧第一步仍有32厘米缺口；
原地转向可以持续获得接近完整的零线速度跟踪奖励；大量关节动作在归一化裁剪范围外。
这支持修改训练机制，不能单凭这些现象断言修改后就能跨越或跳墙。

## 1. 阶段奖励与动作边界

- 梅花桩、绕桩：原有基础正向塑形随新增最远路线距离发放；平移指令低于
  0.05 m/s 且存在转向指令时，随当前航点的新增最佳朝向改善发放。
  不动、后退再回来、反复摆头不会重复获得这一部分奖励。负值完整保留。
- 每脚每桩的有效落脚事件、朝向进展事件和出口事件独立保留。高墙沿用墙体进展门控。
- 策略高斯均值使用 `x/(1+abs(x))`；有效标准差限制在0.05～0.35，默认0.25。
  训练概率、KL、确定性回放、ONNX 和 TorchScript 使用一致的均值映射。
  **高斯采样仍可能超过±1**，环境仍裁剪执行；这不是完全有界采样。
  应持续观察原始动作裁剪率，不能将“均值受限”当作越界已消失。
- 默认关节目标映射仍为0.3 rad；工作台可试0.5，但需另建实验比较。

## 2. 梅花桩入口辅助逐档撤除

左右错位0.30 m、纵向中心间距0.60 m不变。仅在右侧入口平台增加与桩顶等高的窄舌台。

| 档位 | 右侧辅助延伸/m | 辅助平台末端至第一桩缺口/m | 每侧桩数 |
|---|---:|---:|---:|
| 1 | 0.240 | 0.080 | 2 |
| 2 | 0.220 | 0.120 | 3 |
| 3 | 0.180 | 0.180 | 4 |
| 4 | 0.135 | 0.240 | 5 |
| 5 | 0.090 | 0.300 | 6 |
| 6 | 0 | 0.400 | 6 |
| 7 | 0 | 0.410 | 6 |
| 8 | 0 | 0.420 | 6 |

第六档为比赛尺寸，6～8档的全部几何与完整强化课程逐项一致。辅助台本身不算有效桩顶
落脚奖励，周围地面继续按原触地失败规则检查。最终需在完整课程验收。

## 3. 前脚越墙引导与感知对照

沿用每墙有限抬脚/跨越提示，新增前脚接近“墙中心后8 cm、墙顶上4 cm”目标的
历史最佳距离改善奖励。每前脚每墙最多0.5分，两前脚合计最多1分，不能原地循环补充。
重置后的初始姿态不发奖，失败与出界不发奖。此目标用于引导抬脚跨越，不要求固定跳跃动作。
墙附近和绕桩仍局部减速至0.25 m/s，巡航从0.6 m/s起步，扩速上限2.0 m/s。

工作台“策略地形输入”可选：

| 输入 | Actor 输入 | 用途 |
|---|---|---|
| D435i 深度 | 188维自身历史 + 64维冻结感知特征 | 正常训练，可进入后续实机验证 |
| 地形真值对照 | 188维自身历史 + 187维仿真高度扫描 | 仅仿真诊断，无需感知预训练 |

真值扫描从 critic 的高度观测复制给 actor，关闭该组噪声；critic 观测不变。
这是局部高度图对照，并非完美未来信息，不能通过一次成功/失败彻底排除感知问题。
两组应从头训练，保持相同种子、地形、动作映射、奖励、环境数量及采样预算，并用多个种子
比较通过率、停滞、前脚净空、实际速度、动作裁剪率。真值组学得更好说明深度表征值得继续检查；
两组都失败时优先检查动作控制、接触、奖励与任务难度。

## 启动与兼容

正常深度组，先完成D435i下俯20°感知预训练：

```bash
python -m scripts.train LgDog1-Race-MGDP-WallTraining-D435i20 \
  --mgdp-skill-training=True --mgdp-action-scale=0.3 \
  --env.scene.num-envs=1024 --terrain-num-rows=8 --terrain-num-cols=10 \
  --agent.seed=42 --agent.run-name=skillv2_depth_seed42
```

真值对照组，同样参数另开独立目录；不要同时占满同一张GPU：

```bash
python -m scripts.train LgDog1-Race-MGDP-WallTraining-D435i20 \
  --mgdp-skill-training=True --mgdp-action-scale=0.3 \
  --mgdp-vision-mode=height_oracle \
  --env.scene.num-envs=1024 --terrain-num-rows=8 --terrain-num-cols=10 \
  --agent.seed=42 --agent.run-name=skillv2_oracle_seed42
```

旧深度策略可用 `--warm-start-checkpoint=...` 仅迁移actor，优化器、critic、课程重新开始；
均值映射改变，迁移后的第一步行为不等于旧模型行为。正式输入对照实验建议两组均从头训练。
深度与真值的输入维度不同，不允许互相迁移或完整续训。真值检查点可在真值模式下完整续训。
技能V1与V2不允许混用完整续训；旧V1模型回放自动恢复原奖励、入口与高斯分布。
新V2回放恢复受限均值映射。真值ONNX标记 `simulation_only=true`，部署/Sim2Sim入口会拒绝，
应使用 `scripts/play.py` 在训练环境回放。

CPU训练、续训、导出和兼容测试仅证明工程流程可运行，不证明GPU收敛、跳墙或比赛通过率改善。

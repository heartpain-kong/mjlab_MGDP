# MGDP v2：定向越障训练

本次修改针对 MGDP_V3 的“看到障碍但不通过”：MGDP 比赛任务先训练固定方向、固定入口和出口的障碍通道。训练 ID 仍为 `LgDog1-Race-MGDP`，短名 `race_mgdp`；实验目录改为 `lgdog1_velocity_race_mgdp_v2`。普通 `mgdp` 使用新的独立 reward profile、接触规则和能力门控扩速，目录改为 `lgdog1_velocity_mgdp_v2`。

## 目标与地形

- 每块地形 8×8 m，入口局部坐标 `(1,4,0)`，朝世界 +X；位置与朝向只加 ±0.03 的小扰动。
- 障碍布置在约 x=2.3–5.6 m，出口为 x=6.3 m（相对入口 +5.3 m）。入口与出口是安全平地。
- 机器人中心必须保持在中心线 ±0.28 m 内；越界或后退超过入口 0.5 m 判失败，防止从障碍侧面绕出通道。
- 桩、梁、台阶、砖块、绕桩、墙、笼子、轮胎、粗糙地形和简单平地各占 10%。默认 10 行×20 列，开局只用第 0 行。
- 难度从宽梁、小间隙、低墙、高净空、低轮胎逐渐增加。难度与路径合同不同于原随机速度任务；这不是整个比赛场地的复刻。
- 到达出口且没有物理失败，获得一次性 5 分通过奖励并结束回合。每回合最多 30 秒。

完整比赛仍在 sim2sim 的 `--map race` 上评估；课程中的通过不能等同于整个比赛成功。

## Reward

基础参数集中于 `reward_cfg.py` 的 `mgdp` profile，面板按独立 profile 编辑。新增任务奖励在 `make_mgdp_passage_rewards()` 中。

| 项目 | 默认值 | 用途 |
|---|---:|---|
| foot_clearance | **0** | 关闭抬腿高度奖励 |
| feet_air_time | **0.25** | 数腾空时间在 0.05–0.35 秒内的脚，值为 0–4 |
| track_linear_velocity | 2.0 | 绝对误差/相对误差各占 50%，相对标准差 0.5，最小命令速度 0.2 m/s |
| track_angular_velocity | 1.0 | 朝向稳定 |
| pose | 0.5 | 降低默认站姿约束，给跨越和下蹲留动作空间 |
| foot_gait | 0 | 不强制固定相位步态 |
| action_rate_l2 | -0.1 | 动作平滑 |
| leg_contact_force | -0.25 | 轻度腿擦碰仍有代价 |
| soft_landing | -0.002 | 落地冲击代价 |
| passage_progress | 1.0 | 只奖励新达到的前向位置，按前进速度计，最大 1 m/s；往返重复走不重复得分 |
| passage_success | 5.0 | 出口固定一次性奖励，函数补偿 reward manager 的 dt 缩放 |

机身姿态、关节限位、滑动、stumble 等代价保留公共基线。成功到出口不领取 `is_terminated` 的失败惩罚；同一步发生机身碰撞等失败时，不发通过奖励。

## 接触与课程

- 机身单独传感器，超过 10 N 即终止。
- 腿单独按碰撞几何记录力历史，允许短暂轻擦：同一个几何超过 10 N 持续 0.1 秒才终止，超过 80 N 立即终止。复位只清空对应环境的计数。
- 地形升级必须真正通过且该回合平均 XY 速度误差 ≤0.25 m/s；失败则降一级；顶行不随机回绕。
- 起始前进速度 0.25–0.35 m/s；朝向目标始终为 +X，同时给一个小幅回中心线指令。回合中不随机改成横移/掉头任务。
- 每个地形列至少 32 个真实完成回合；所有障碍类型必须存在，缺失样本不视为通过。各列成功率 ≥70%、平均误差 ≤0.25 m/s，连续 3 个统计窗口通过，才将速度上限增加 0.025 m/s，最高 0.6 m/s。
- 样本充足且任一列成功率 <35% 或误差 >0.4 m/s，速度上限回退 0.025，最低回到 0.35 m/s。初始化、手工中途复位、首回合随机长度不参与统计。
- `Curriculum/passage/success_rate/<障碍>` 与 `samples/<障碍>` 一起查看；样本为 0 时不能解读为已测得的 0% 成功率。
- 定向任务独立管理速度与地形，不叠加 LP/uniform 或正负速度包络；面板会禁用相应覆盖项，直接 CLI 冲突会报错。

课程状态保存于 checkpoint 的 `infos.mgdp_passage_curriculum`，包含计数、速度、连续达标次数、地形行列和参数指纹。完整续训要求相同的环境数与任务合同。旧 MGDP 没有该状态，不能直接完整续训为 v2；已有文件保留用于原配置回放。

## 开始新训练

先使用已经修复 GRU 序列损失的预训练代码生成新的感知文件，然后开始新的策略训练。旧策略要继续配对原来的感知权重。

```bash
python -m scripts.pretrain_mgdp --num-envs 256 --steps 4000 --sequence-length 8 --iterations 3000
python lgdog.py train race_mgdp --envs 1024 --iterations 16000
```

环境数先按显存小规模确认。以上长训练本轮未执行。

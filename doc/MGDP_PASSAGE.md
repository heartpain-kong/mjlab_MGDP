## 目标与地形

- 每块地形 8×8 m，入口局部坐标 `(1,4,0)`，朝世界 +X；位置与朝向只加 ±0.03 的小扰动。
- 普通直线课出口为 x=6.3 m（相对入口 +5.3 m）；加长梅花桩出口为 x=7.5 m。
  连续课将L形砖木坑旋转90°放在绕桩末端，经过连接段进入砖木坑，
  完成两部分才在 `(7,4.15)` 计通过；中途不复位、不发单项通过奖励。
- 机器人中心须保持在当前路线段两侧 0.28 m 内；依次进入半径 0.15 m 的路点才推进。
  未完成前面路点，直接到最终出口不算成功。所有课的起点和终点均在平地上。
- 当前10类课程各占1/10：平地、梅花桩、单木桥、沟壑、高墙、匍匐、轮胎阵、随机高低起伏、
  mjlab原生随机粗糙高度场、绕桩→砖木坑连续课。默认10行×20列，每类两列，开局只用第0行。
- 难度从低桩、宽梁、小平台间隙、低墙、高净空、低轮胎递进。
  梅花桩每组双排12桩，横向7组共84桩，沿用参考单元的0.6m纵向间距，平台与桩区总长5.3m；
  沟壑包含实心斜坡、双平台和两级下台阶，横向9单元相接覆盖7.2m；单木桥宽0.7→0.4m，
  按桥宽自动排7→9条，相邻边缘固定留0.4m空隙。绕桩是 L 形六根矮圆柱；
  砖木坑包含 L 形槽体、护栏与斜分隔栏。移除旧课人为增加的 0.45 m 深坑。
- 两类新课使用实际可碰撞高度场。连续随机起伏高度0.025→0.20m，原生随机粗糙幅度0.02→0.10m；
  出生区与出口降为平地，边缘平滑衔接。没有加入坡面/阶梯混合图。
- 到达最后路点且没有物理失败，获得一次性5分通过奖励并结束回合。每回合最多 **75秒**，
  指令重采样间隔76秒，容纳约12.9m的连续路线。此为训练回合上限，MuJoCo交互窗口仍运行至关闭。

完整比赛仍在 sim2sim 的 `--map race` 上评估；课程中的通过不能等同于整个比赛成功。

## HIMLoco 全强度域随机化

比赛策略训练和比赛感知采集采用 HIMLoco 发布代码范围：机身附加载荷 −1～+2 kg，
惯量与质量联动，质心 XYZ 各 ±0.05 m；复位时重采样摩擦 0.2～1.25、
Kp/Kd/电机强度各 0.9～1.1 倍及初始关节位置 0.5～1.5 倍。
每个策略步有 0～15 ms 子步动作延迟，每 8 步施加局部 XYZ 各 ±30 N 的 5 ms 外力脉冲，
每 16 s 将 XY 速度设为各 ±1 m/s 范围内随机值。保留 10/10/20 Nm 力矩上限。
新质量配置替换此前 ±10% 倍率；腿部保持名义质量和惯量。
配置、原版适配差异和验证见 [域随机化说明](MGDP_DOMAIN_RANDOMIZATION.md)。
新启动环境自动生效，旧课程晋级统计不直接迁入新物理配置。

## Reward

基础参数集中于 `reward_cfg.py` 的 `mgdp` profile，面板按独立 profile 编辑。新增任务奖励在 `make_mgdp_passage_rewards()` 中。

| 项目 | 默认值 | 用途 |
|---|---:|---|
| foot_clearance | **0** | 关闭抬腿高度奖励 |
| feet_air_time | **0.25** | 数腾空时间在 0.05–0.35 秒内的脚，值为 0–4 |
| track_linear_velocity | 2.0 | 绝对误差/相对误差各占 50%，相对标准差 0.5，最小命令速度 0.2 m/s |
| track_angular_velocity | 1.0 | 朝向稳定 |
| pose | 0.5 | 降低默认站姿约束，给跨越和下蹲留动作空间 |
| foot_gait | 0 | 不强制固定相位步态 |
| action_rate_l2 | -0.1 | 动作平滑 |
| leg_contact_force | -0.25 | 轻度腿擦碰仍有代价 |
| soft_landing | -0.002 | 落地冲击代价 |
| passage_progress | 1.0 | 只奖励沿路线新达到的里程，包含转弯后的 Y 方向；最大 1 m/s，往返不重复得分 |
| passage_success | 5.0 | 出口固定一次性奖励，函数补偿 reward manager 的 dt 缩放 |

机身姿态、关节限位、滑动、stumble 等代价保留公共基线。成功到出口不领取 `is_terminated` 的失败惩罚；同一步发生机身碰撞等失败时，不发通过奖励。

## 接触与课程

- 机身单独传感器，超过 10 N 即终止。
- 腿单独按碰撞几何记录力历史，允许短暂轻擦：同一个几何超过 10 N 持续 0.1 秒才终止，超过 80 N 立即终止。复位只清空对应环境的计数。
- 地形升级必须真正通过且该回合平均 XY 速度误差 ≤0.25 m/s；失败则降一级；顶行不随机回绕。
- 初始路线速度 0.25–0.35 m/s，接近路点时减速；平移与朝向指令随当前路线段变化，
  转角处允许横移和转向（角速度上限 0.8 rad/s），直线课沿 +X。
- 每个地形列至少 32 个真实完成回合；所有障碍类型必须存在，缺失样本不视为通过。各列成功率 ≥70%、平均误差 ≤0.25 m/s，连续 3 个统计窗口通过，才将速度上限增加 0.025 m/s，最高 0.6 m/s。
- 样本充足且任一列成功率 <35% 或误差 >0.4 m/s，速度上限回退 0.025，最低回到 0.35 m/s。初始化、手工中途复位、首回合随机长度不参与统计。
- `Curriculum/passage/success_rate/<障碍>` 与 `samples/<障碍>` 一起查看；样本为 0 时不能解读为已测得的 0% 成功率。
- 定向任务独立管理速度与地形，不叠加 LP/uniform 或正负速度包络；面板会禁用相应覆盖项，直接 CLI 冲突会报错。

课程状态保存于 checkpoint 的 `infos.mgdp_passage_curriculum`，包含计数、速度、连续达标次数、地形行列和参数指纹。
指纹包含布局版本、路线、回合时长和命令配置。**v2或旧布局v3的完整训练状态不兼容当前布局7，需开始新的训练run**；
不要复用旧的地形掌握度和扩速统计。旧导出策略仍可与原感知 sidecar 在 sim2sim 中回放。

## 开始新训练

先使用已经修复 GRU 序列损失的预训练代码生成新的感知文件，然后开始新的策略训练。旧策略要继续配对原来的感知权重。

```bash
python -m scripts.pretrain_mgdp --task LgDog1-Race-MGDP --num-envs 256 --steps 4000 --sequence-length 8 --iterations 3000
python lgdog.py train race_mgdp --envs 1024 --iterations 16000
```

比赛感知文件默认输出 `logs/mgdp/perception/mgdp_race_v3.pt`，与普通 Rough 感知文件分开。
比赛预训练采集新的 2027 障碍图，朝向入口前方，覆盖全难度；不会再只采集 Rough 图。
环境数先按显存小规模确认。以上长训练本轮未执行。

查看当前任务的实际训练图：

```bash
python -m scripts.visualize_terrain --task LgDog1-Race-MGDP
python -m scripts.preview_2027_training
python -m scripts.preview_2027_overview
```

工作台的“打开 3D 查看器”和“预训练感知模型”均随所选任务启动。3D 界面可选具体障碍，
从低到高查看课程并显示 LgDog1 模型；编辑卡里的普通 Rough 参数不用于修改 2027 图。

# 技能V5：最终参数、阶段诊断与渐进短课程

V5继承V4两道宽间距墙、近墙0.35 m/s、墙外/绕桩0.6 m/s、高墙距离奖励和桥段踩地约束。旧V2～V4仍按原版本恢复。改变课程必须新建训练或只迁移策略。

## 工作台入口

训练设置中勾选“技能引导”，选择“V5：渐进短课程＋最终参数＋阶段诊断”。

- 设置页“新训练最终生效参数预览”和奖励页“最终生效值与覆盖来源”显示输入基线、实际值和覆盖来源；技能开关/版本/参数输入变更时刷新。预览不保存输入。
- 高墙规则编辑器明确编辑的是保存基线；技能版本覆盖由训练与工作台共用的解析函数计算。
- 当前技能覆盖仍为进展参考0.15m/s、等待宽限1.5秒、等待递增2秒、最大0.5分/秒、无进展6秒。参数方向未被此次界面修复暗改。
- 每次新训练保存params/effective_wall_rules.json，右侧诊断卡显示正在查看的运行的实际配置；旧运行没有该快照时不猜测、不回填。

## 八档阶段目标

|地形|第1档|第2档|第3档|第4档|第5档|第6～8档|
|---|---|---|---|---|---|---|
|高墙|第一墙后结束|第一墙后结束|完整两墙|完整两墙|完整两墙|完整两墙|
|沟槽台阶|第一组结束|第一组结束|第一组结束|完整两组|完整两组|完整两组|
|绕桩接坑|路线前3段|前5段|前7段|前10段|前14段|完整18段|

- 场地仍保留两道墙；高墙初期终点在出生点前方2.1米，且四脚必须越过本阶段最后一道墙的后缘及配置净空距离，避免只有根部过去即升级。
- 沟槽第一组包含上楼梯→过沟→下坡，终点使用连接平地的60cm，让后脚有空间下坡；完整第二组为上坡→过沟→下楼梯。
- 绕桩路线只截取已存在的安全路线前缀，不为缩短课程另造穿桩捷径。前三档对应先练1～3根桩，再练完整绕桩段和接坑。
- 几何尺寸、碰撞、走廊宽度、连续两回合升级、防刷进展奖励均保留；阶段目标随当前地形行选择，同批环境可处于不同阶段。
- 阶段终点复用已有一次终止成功奖励；已存在的最远路线距离奖励持续提供进度反馈，没有新增可循环刷取的路点奖励。

第6档正常训练仍是V4两墙辅助场地，完整原三墙赛道必须走下述独立验收入口。

## 分地形、分难度、分终止阶段诊断

右侧“分地形 / 终止阶段诊断”按已完成回合累计：地形、难度档、终止位置、回合数/成功数、各终止原因、平均时长、平均路线进度。沟槽分别识别楼梯、第一沟、下坡、连接平地、上坡、第二沟及出口；高墙识别两墙附近；绕桩按实际路线段识别。

计数在有效回合结束、更新课程难度之前完成；初次随机回合长度制造的假超时不计入。每个回合只计一次，多个终止原因可同时记录，原因之和可超过回合数。成功是当前阶段目标成功，不是完整比赛通过率，也不是对每个经过阶段的独立通过率。

CPU/GPU计数缓冲留在训练设备，按重置批次聚合，复用5秒快照节流写curriculum/passage_diagnostics.json。完整续训恢复累计计数；策略迁移从零开始。工作台只读小JSON快照，不逐轮重新读模型或重新仿真。

## 完整赛道验收

普通回放默认恢复V5检查点的阶段目标；勾选回放区“V5完整赛道验收”后，显式改用：

- 完整绕桩接坑路线、完整两组沟槽；
- 原三墙及原1.4米中心间距，沿用八档墙高；
- 完整六对梅花桩，撤去入口辅助。

CLI示例（工程根目录，替换模型路径）：

```bash
python scripts/train.py LgDog1-Race-MGDP-WallTraining-D435i20 \
  --mgdp-skill-training=True --mgdp-skill-version=5 \
  --terrain-num-rows=8 --terrain-num-cols=10

python scripts/play.py LgDog1-Race-MGDP-WallTraining-D435i20 \
  --checkpoint_file=logs/rsl_rl/你的实验/model_100.pt --full-course=True
```

完整验收改变了场景和目标，必须单独记录结果。该开关仅面向V5；不能把旧模型自动套入新阶段规则。完整赛道默认固定第6档，可通过验收难度输入或--full-course-level=1..8选择；回放中保持该档，不随机换档。至少10个环境可覆盖全部障碍列。

# 比赛MGDP的机身质量与惯量随机化

日期：2026-11-05。适用 `race_mgdp` / `LgDog1-Race-MGDP`。

机身 `trunk` 的质量和质心处完整惯量张量使用同一个倍率，范围 **0.9–1.1**。
每个并行环境在初始化时独立抽样，随后保持该倍率，回合复位不重新抽取。
名义机身质量3.487kg，对应范围3.1383–3.8357kg；这是机身本体的范围，腿部不做新增质量或惯量扰动。

| 项目 | 配置 |
|---|---|
| 入口 | `src/tasks/velocity/config/lgdog1/domain_rand_cfg.py` |
| 可编辑范围 | `RACE_MASS_INERTIA_SCALE_RANGE = (0.9, 1.1)` |
| 作用对象 | `robot` 的 `trunk`，不包含腿部 |
| 触发 | `startup` |
| 生效任务 | 比赛策略训练、比赛感知预训练采集 |
| 其他任务与回放 | 普通MGDP/HIM任务不新增此项；`play`也不新增此项，原有其他随机化照旧 |

## 物理一致性

使用当前安装mjlab的原生 `dr.pseudo_inertia`，只打开均匀密度缩放。
该接口的实际倍率为 `exp(2*alpha)`，因此配置alpha范围为
`(0.5*log(0.9), 0.5*log(1.1))`；最终倍率为0.9–1.1内的对数均匀分布。
其余形变、剪切、平移参数保持零。质量和惯量联动缩放，惯量保持正值和物理可行性。
惯量的主轴表示可能重新排序，验证使用重建后的完整惯量张量比较，不能只按三个数组槽位比较。

原生接口从名义参数重建伪惯量，会写回机身质心位置。因此此事件放在既有 `base_com` 之前，
随后再执行原来的质心XYZ各±0.05m偏移，避免覆盖既有随机化。
事件声明了质量、惯量、质心及主轴旋转字段，并由mjlab重新计算相关动力学常数。
腿部质量/惯量、PD、电机能力、控制时延和比赛推搡配置不随本次修改变化。

## 使用

新创建环境时自动生效，正在运行的训练不会热更新。原有命令不变。
比赛感知预训练采用同一配置，输出权重新增 `mass_inertia_scale_range` 元数据。
观测和策略网络维度不变；建议用新run对照评估，旧统计不能直接作为新随机化下的通过率。

## 验证

回归覆盖倍率边界、启动顺序、任务隔离、感知采集配置一致性，以及质量/完整惯量张量的同比缩放、
未选身体不变、重复调用不累乘和子集环境选择。
CPU集成检查记录位于 `.artifacts/mass-inertia/`；这些检查验证实现，不代表实机迁移或越障成功率提高。

| 检查 | 结果 |
|---|---|
| 全套回归 | 263项，0失败、1跳过；`all-tests.log` |
| 实际CPU仿真 | 10环境、2行×10列，验证质量/完整惯量张量同比、其他身体不变、原质心偏移保留 |
| 实际抽样 | seed42下倍率约0.94946–1.08566，机身质量约3.31075–3.78569kg，均在配置范围内 |
| 复位和执行 | 再次复位及5个仿真控制步后倍率保持，观测/奖励有限；`verified-actual.log` |
| 感知链路 | CPU采集16步、30条连续4帧序列，更新2次并保存；权重中的倍率元数据为(0.9,1.1) |

未执行GPU长训、实机部署或性能对比。

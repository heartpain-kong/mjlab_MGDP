# 技能规则V3：桥面落脚约束与高墙距离奖励

适用于比赛尺寸强化课程及D435i下俯20°版本。工作台勾选技能引导，选择
“V3：高墙距离奖励＋桥面落脚约束”。V2仍可选择，旧模型按保存版本回放。

## 单木桥判定修正

此前判定主要依赖根部沿路线到达出口。检查同一训练4600轮第6档回放，左侧脚保持
约10cm桥面高度，右侧脚在桥侧地面附近，仍被判为成功。这不等于四脚有效过桥。

V3新增 `beam_ground_contact` 失败项：仅在单木桥列、桥段纵向范围内检查；
每个物理子步中，任意一只脚有有效承重地面接触即失败。桥前和桥后平地、空中摆腿、
桥顶接触不因此失败。边缘纵向各留3cm接触过渡，桥本体尺寸不变。

参数：cell X范围2.53～5.47m，地面容差0.008m，有效接触力至少1N、接触法线Z绝对值大于0.7。
只要失败，出口奖励和成功课程统计都不计入该回合；原机身碰撞等失败项保留。
已有V2单木桥成功率不能作为这项严格规则下的通过率。

## 高墙以新增距离引导

V2已有新增最远路线距离奖励，但仍包含进展门控后的速度跟踪正奖励。
V3仅在高墙列取消线速度与角速度跟踪的正奖励。其他地形的速度跟踪规则不变，
负值与独立安全惩罚保留。

高墙继续使用：新增最远路线距离奖励（当前基础权重1.5）、每墙一次奖励（基础5分）、
出口奖励（基础10分）、有限前脚接近/抬脚提示、进展门控后的其他塑形和安全惩罚。
距离只在超过历史最远路线位置时计奖，后退再回来不能重复刷；
累计奖励按新增距离线性计算，不要求维持固定的越墙速度。V3的高墙距离奖励额外取消原
通用进展项每步最多按1m/s记奖的裁剪，快速跨越也按完整新增距离计奖；其他地形保留原规则。

巡航指令和墙附近0.25m/s的限速继续提供方向/控制参考；取消速度跟踪正奖励并不修改
actor的指令观测。高墙几何和八档尺寸保持原配置。全局扩速仍沿用原通过率和误差门。

## 使用与兼容

```bash
python -m scripts.train LgDog1-Race-MGDP-WallTraining-D435i20 \
  --mgdp-skill-training=True --mgdp-skill-version=3 \
  --mgdp-action-scale=0.5 --env.scene.num-envs=7168 \
  --terrain-num-rows=8 --terrain-num-cols=10 \
  --agent.run-name=skillv3_seed42 --agent.seed=42
```

可添加 `--warm-start-checkpoint=旧模型路径` 只迁移策略，新建课程、critic和优化器。
V2与V3的奖励/终止不同，不能混用完整续训。相同V3规则的检查点可完整续训。
已有V2回放保留其原判定，避免把新规则误当成历史模型训练条件。

训练生效配置在新run的 `params/env.yaml` 中；全局奖励面板显示基础权重，V3高墙取消
速度正奖励属于按地形筛选。新增 `Episode_Termination/beam_ground_contact` 日志是
终止数量统计，并非直接的失败百分比。

## 绕桩回放时限

V2路线约18.95m，局部指令上限0.25m/s，名义巡航时长约76秒；20秒录像不足以验完整路线。
训练原时限120秒，不应根据20秒录像就归因于训练超时。长回放用于观察真正结束原因；
回放随机化不同于训练，单次结果不能替代通过率统计。

这些修改修正奖励与判定，工程测试通过不代表已经学会跨墙或按严格规则过桥，仍需GPU对照训练。

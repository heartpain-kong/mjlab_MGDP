# 技能规则V4：两道宽间距高墙与速度调整

在比赛尺寸强化课程的技能引导中选择V4。继承V3的高墙新增距离奖励、桥段有效地面接触失败判定、
梅花桩入口辅助、受限均值动作分布。旧V2/V3可继续选择并按原规则回放。

## 高墙几何

- 每个场地、全部八档均为两道墙，中心X为2.3、4.7米，中心间距2.4米。
- 墙厚0.08米，净间距2.32米；相较原1.4米中心距提供更多落地/准备空间。
- 八档高度保留当前统一课程的10、12、15、18、24、30、35、40厘米。
- 地形几何、墙前减速、跨墙奖励、等待惩罚、抬脚目标使用同一套墙位置；第三个内部状态槽始终不激活。
- 这是两墙辅助课程。第6档保留参考墙高，墙数和间距已按本次要求修改，不能直接当成原三墙赛道验收。

## 指令速度

用户确认沿用已知墙位置的距离判断，不使用深度图识别墙的结果触发减速。

| 区域 | 巡航指令上限 |
|---|---:|
| 距任意有效墙中心前后0.6米内 | 0.35 m/s |
| 高墙场地其余区域 | 0.6 m/s |
| 绕桩路线，含横移 | 0.6 m/s |

这些是上限：原始巡航速度更低时沿用较低值；原有航点接近减速仍然保留，不保证每一帧指令严格等于上限。
其他地形仍使用现有巡航/扩速规则。实际机器人速度不等同于指令速度。

## 绕桩时限判断

整条绕桩接砖木坑路线约18.95米。按0.25 m/s名义巡航约76秒；按0.6 m/s约32秒，均未包含航点减速、
准备、失误修正。训练原时限为120秒，本次保留。原20秒录像不足不能证明训练也超时。
若仍无课程进展，需要分地形统计出界、碰桩、无进展终止及实际走到哪个航点；不能仅用全局通过率推断时间原因。

## 使用与兼容

工作台勾选技能引导，版本选择V4；命令行增加：

```bash
--mgdp-skill-training=True --mgdp-skill-version=4
```

V3/V2转V4必须新建训练，或用`--warm-start-checkpoint`仅迁移策略。完整续训需要原V4相同的规则和几何。
训练/回放配置记录版本4，旧模型恢复原版本，避免改动历史模型的行为口径。

沟槽台阶几何未修改。已输出第1档与第6档的侧视、俯视和正视图，按实际MuJoCo box/mesh顶点投影；
侧视和正视为便于阅读放大高度，坐标及尺寸标注为真实数值。

CPU流程和单元检查不代表GPU显存、训练收敛或新速度下的越障通过率已验证。
